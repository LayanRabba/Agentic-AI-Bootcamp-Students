# Module 1 — Agent Reflection

During the multi-tool test, my agent successfully used the lookup tool to find the capital of France and the calculator tool to calculate 12 × 12. One possible failure was receiving an invalid JSON response, which could prevent the agent from understanding its next action. I tested this situation using a simulated invalid response, and the Bad-JSON Retry guard successfully recovered after one correction attempt. Another possible failure was repeatedly calling the same tool with identical arguments instead of progressing toward a final answer. In my simulated loop test, the agent requested the capital of France twice, and the Loop Detection guard stopped the repeated action. Adding more tools makes the agent harder to keep reliable because it must choose the correct tool, provide valid arguments, and handle each tool's output correctly. These tests showed me why validation, retry mechanisms, and stopping conditions are important when building autonomous AI agents.
